\doxysubsection{Detailed Description}
Represents the elevator car within the elevator system. 

Represents an elevator car in the elevator system.

The \doxylink{class_elevator_car}{Elevator\+Car} stores the current floor of the elevator and provides functions for moving the elevator up or down. Each movement is logged using Logger\+Trait.

The class extends \doxylink{class_node}{Node} to inherit common node information.

The \doxylink{class_elevator_car}{Elevator\+Car} class stores the car ID, current floor, and current direction. Private properties are accessed and modified through class methods to demonstrate encapsulation.
