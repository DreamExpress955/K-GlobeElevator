\doxysubsection{Detailed Description}
Provides a connection to the elevator My\+SQL database. 

The \doxylink{class_database}{Database} class stores the database connection information as private static properties. The \doxylink{class_database_a12df9b62f20181459bea5f2c4f9a8990}{connect()} method uses these properties to create and return a My\+SQL database connection.
