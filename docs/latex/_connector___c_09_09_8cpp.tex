\doxysubsection{Detailed Description}
Tests the My\+SQL Connector/\+\+C++ connection and elevator database functions. 

This program tests communication between the elevator application and the My\+SQL Elevator database. It uses the functions provided by database\+Functions.\+h to read and update elevator information and to log CAN messages.

\begin{DoxyNote}{Note}
This project uses My\+SQL Connector/\+\+C++ and Boost 1.\+85. 

Apache and My\+SQL must be running before database operations are tested. 
\end{DoxyNote}
