\doxysubsection{Detailed Description}
Represents a distance sensor in the elevator system. 

The \doxylink{class_sensor}{Sensor} class stores a distance measurement as a private property. The measurement can be accessed using \doxylink{class_sensor_a9986a3e09b7d82dfbe9f6026a661b4c7}{read\+Distance()} and updated using \doxylink{class_sensor_ad1a5e8db8b60ae790bfc4725dc0dde78}{set\+Distance()}.

This class demonstrates encapsulation by keeping the distance value private and providing public methods to access and modify it.
