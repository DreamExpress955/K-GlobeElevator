\doxysubsection{Detailed Description}
Implements elevator floor audio announcements. 

Provides the audio functionality used by the Service Controller. The \doxylink{audio_8cpp_a7128831d69e28646a7ca9ec88ea9dc55}{play\+Floor()} function plays a different WAV audio file depending on the elevator floor number supplied.

Plays the audio associated with an elevator floor.

Selects and plays the WAV file associated with the supplied floor number. The Linux aplay command is used to play the audio file.
