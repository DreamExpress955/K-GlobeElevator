\doxysubsection{Detailed Description}
Implements menu and conversion functions for the elevator Service Controller. 

Provides the user menus used by the Service Controller to select operating modes, CAN message IDs, and elevator floor commands.

This file also contains utility functions for converting between elevator floor numbers and the hexadecimal CAN command values used by the K-\/\+Globe Elevator system.

Displays the main Service Controller menu. 

Displays the Service Controller menu and gets a user selection.

Allows the user to select one of six Service Controller operating modes. The function continues prompting until a valid selection between 1 and 6 is entered.

Menu options include:
\begin{DoxyItemize}
\item 1: Transmit a CAN message.
\item 2: Receive CAN messages.
\item 3: Control the elevator from the website.
\item 4: Run the elevator demo mode.
\item 5: Exit the program.
\item 6: Run the K-\/\+Globe receive/\+transmit mode.
\end{DoxyItemize}
