\doxysubsection{Detailed Description}
Declares database functions used by the elevator Service Controller. 

Provides functions for communicating with the Elevator database. The Service Controller can use these functions to read and update elevator floor information, process website requests, log CAN messages, update the elevator door status, and read the elevator stop flag.
