\doxysubsection{Detailed Description}
Displays the current elevator door status. 

Connects to the Elevator database using the database functions provided by \doxylink{database_functions_8php}{database\+Functions.\+php} and retrieves the current door status.

A green Bootstrap badge is displayed when the elevator door is open, and a red Bootstrap badge is displayed when the elevator door is closed.
