\doxysubsection{Detailed Description}
Tests inheritance and activation of elevator system components. 

Creates an \doxylink{class_elevator_car}{Elevator\+Car}, multiple \doxylink{class_call_button}{Call\+Button} objects, and a \doxylink{class_distance_sensor}{Distance\+Sensor} to test the shared \doxylink{class_node}{Node} inheritance and component functionality.

The test moves the elevator, activates each call button, activates the distance sensor, and displays the elevator\textquotesingle{}s final floor.
