\doxysubsection{Detailed Description}
Provides the access request page for the K-\/\+Globe Elevator system. 

Allows a user to request access to the elevator dashboard by submitting a username and password.

Submitted credentials are inserted into the authorized\+Users database. After a successful request, the user is redirected to the login page.
