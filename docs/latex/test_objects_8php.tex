\doxysubsection{Detailed Description}
Tests the basic OOP classes used in the elevator system. 

Creates objects from the \doxylink{class_node}{Node}, \doxylink{class_elevator_car}{Elevator\+Car}, \doxylink{class_floor_node}{Floor\+Node}, \doxylink{class_call_button}{Call\+Button}, and \doxylink{class_sensor}{Sensor} classes to demonstrate their basic functionality.

The test displays node information, reads the elevator\textquotesingle{}s current floor, calls the elevator from a floor, presses a call button, reads a sensor distance, and displays the total number of \doxylink{class_node}{Node} objects created.
