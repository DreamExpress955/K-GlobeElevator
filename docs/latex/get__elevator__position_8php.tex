\doxysubsection{Detailed Description}
Displays the current elevator floor using visual status indicators. 

Connects to the Elevator database using the functions provided by \doxylink{database_functions_8php}{database\+Functions.\+php} and retrieves the elevator\textquotesingle{}s current floor.

Three floor indicators are displayed on the page. The indicator for the elevator\textquotesingle{}s current floor is shown in green, while the indicators for the other floors are shown in red.
