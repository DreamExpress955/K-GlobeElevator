\doxysubsection{Detailed Description}
Provides basic validation and control functions for the elevator. 

The \doxylink{class_elevator_controller}{Elevator\+Controller} validates several parts of the elevator system, including requested floors, network communication, sensor readings, and CAN node IDs.
