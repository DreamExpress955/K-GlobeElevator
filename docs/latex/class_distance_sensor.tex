\doxysubsection{Detailed Description}
Represents a distance sensor in the elevator system. 

A \doxylink{class_distance_sensor}{Distance\+Sensor} is an elevator network node that stores a distance measurement. When activated, the sensor logs its current reading in centimeters.

The class extends \doxylink{class_node}{Node} to inherit common node properties, implements \doxylink{interface_activatable}{Activatable} to provide activation functionality, and uses Logger\+Trait for message logging.
