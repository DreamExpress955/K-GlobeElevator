\doxysubsection{Detailed Description}
Defines the \doxylink{class_node}{Node} class for the OOP elevator system. 

Represents a node in the elevator network. Each node stores information including its node ID, status, current floor, requested floor, and additional information. The class also provides database access and keeps track of the total number of \doxylink{class_node}{Node} objects created.
