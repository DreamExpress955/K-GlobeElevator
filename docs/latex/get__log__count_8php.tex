\doxysubsection{Detailed Description}
Displays the total number of CAN log records. 

Connects to the Elevator database using the functions provided by \doxylink{database_functions_8php}{database\+Functions.\+php} and retrieves the total number of records stored in the CANLogs table.

The resulting log count is displayed on the webpage as a bold heading.
