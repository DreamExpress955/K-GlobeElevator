Detailed Description

Tests inheritance and activation of elevator system components.

Creates an ElevatorCar, multiple CallButton objects, and a DistanceSensor to test the shared Node inheritance and component functionality.

The test moves the elevator, activates each call button, activates the distance sensor, and displays the elevator's final floor.
