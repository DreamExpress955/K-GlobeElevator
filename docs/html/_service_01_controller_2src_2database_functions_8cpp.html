Detailed Description

Implements database functions used by the elevator Service Controller.

Provides the database functionality required by the K-Globe Elevator Service Controller. These functions communicate with the MySQL Elevator database to read and update elevator information, process website floor requests, log CAN messages, update the elevator door status, and retrieve the system stop flag.
