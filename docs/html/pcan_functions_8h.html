Detailed Description

Declares PCAN communication functions for the elevator Service Controller.

Provides the CAN communication constants and functions used by the K-Globe Elevator Service Controller. This file defines the CAN message IDs used by each elevator node, floor request command values, PCAN status values, and functions for transmitting and receiving CAN messages.

Transmits a CAN message through the PCAN interface.

Sends a CAN message containing the specified CAN message ID and data value.

Parameters
idCAN message identifier.
dataData value to transmit.
Returns
Result of the PCAN transmission operation.

Opens the PCAN USB channel and initializes standard CAN 2.0 communication at 125 kbit/s. A one-byte CAN message is created using the supplied CAN ID and data value before being transmitted.

The PCAN channel is closed after the transmission is complete.

Parameters
idCAN message identifier.
dataData byte to transmit.
Returns
PCAN status value returned by CAN_Write().
