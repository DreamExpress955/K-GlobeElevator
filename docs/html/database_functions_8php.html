Detailed Description

Provides database and CAN network functions for the K-Globe Elevator system.

Contains functions for connecting to the elevator database, performing CRUD operations on elevator and CAN log information, displaying database tables, monitoring maintenance intervals, and controlling elevator operating and door status information.

◆ getMaintenanceStatus()

getMaintenanceStatus ( int $recordCount)

Determines the elevator maintenance status.

Uses the number of database log records to determine whether the elevator is operating normally, requires inspection, is approaching a maintenance interval, or should enter maintenance mode.

Inspection is activated at 325 records, a warning is activated at 350 records, and maintenance mode is activated at 5000 records.

Parameters
int$recordCountNumber of CAN log records.
Returns
array Maintenance status flags and status message.
