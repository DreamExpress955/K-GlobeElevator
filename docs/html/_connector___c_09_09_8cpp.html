Detailed Description

Tests the MySQL Connector/C++ connection and elevator database functions.

This program tests communication between the elevator application and the MySQL Elevator database. It uses the functions provided by databaseFunctions.h to read and update elevator information and to log CAN messages.

Note
This project uses MySQL Connector/C++ and Boost 1.85.
Apache and MySQL must be running before database operations are tested.
