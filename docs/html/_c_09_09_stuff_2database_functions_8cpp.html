Detailed Description

Implements database functions used by the elevator system.

This file contains functions for communicating with the MySQL Elevator database. The functions allow the application to read and update elevator data and record CAN network messages.

Logs a CAN network message in the Elevator database.

Logs a CAN message to the elevator database.

Converts an 8-byte CAN payload into a hexadecimal string and inserts the CAN message information into the CANNetwork database table.

The database entry contains the transmitting node, CAN message ID, data length, message payload, and a description of the message.

Parameters
nodeIDID of the node associated with the CAN message.
messageIDCAN message identifier.
dataLengthNumber of bytes contained in the CAN message.
dataPointer to the CAN message data.
descriptionText description associated with the CAN message.
Note
The current implementation formats eight bytes from the data array. The data pointer should therefore reference an array containing at least eight bytes.
