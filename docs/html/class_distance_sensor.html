Detailed Description

Represents a distance sensor in the elevator system.

A DistanceSensor is an elevator network node that stores a distance measurement. When activated, the sensor logs its current reading in centimeters.

The class extends Node to inherit common node properties, implements Activatable to provide activation functionality, and uses LoggerTrait for message logging.
